# Quickstart

The TaleSide homepage demo runs on Windows and works without a Gemini API key.

1. Install Python 3.12 and leave the Python launcher enabled. [Python 3.12 Windows installer](https://www.python.org/downloads/release/python-31210/)
2. On the TaleSide repository page, choose **Code** → **Download ZIP** and
   extract the ZIP.
3. Double-click **Start TaleSide.cmd** in the extracted TaleSide folder. The homepage
   opens at `http://127.0.0.1:8765`. Keep the launcher window open.
4. Choose **Demo Worlds** from the selector in the bottom right. Hover over
   any World card to preview its artwork.

Close the launcher window when you’re done to stop TaleSide.
