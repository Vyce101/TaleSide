# Changelog

## Unreleased

### Added

- Windows launcher that opens TaleSide in a local browser.
- Worlds homepage with an empty state and demo Worlds that show creation progress, pause, and failure states.
- TXT processing backend that preserves original files, generates Gemini Embedding 2 vectors, and resumes from saved progress.
- Create Worlds from ordered TXT books, review chunks that exceed the model’s token limit before saving, and open saved Worlds to track progress, rename them, or discard them.
